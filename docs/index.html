podshare is a generic, type-safe Go library. Every pod holds the same map[string]T; writes broadcast over a pluggable transport. Reads are local — zero network hop.
Pick your wire: Redis pub/sub, P2P TCP, or roll your own.

type Config struct {
    RateLimit    int             `json:"rate_limit"`
    FeatureFlags map[string]bool `json:"feature_flags"`
}

tr := transport.NewMemoryTransport()
defer tr.Close()

store, _ := podshare.New[Config](ctx, "app-config", tr)
defer store.Close()

store.Set(ctx, "global", Config{RateLimit: 1000})
cfg, _ := store.Get("global")  // local, ~17ns
// Two pods on the same Redis converge automatically.
tr, _ := transport.NewRedisTransport(transport.RedisOptions{
    Addr: "localhost:6379",
})
defer tr.Close()

store, _ := podshare.New[Flag](ctx, "feature-flags", tr,
    podshare.WithNodeID[Flag]("pod-1"),
    podshare.WithErrorHandler[Flag](func(e error) {
        slog.Error("podshare", "err", e)
    }),
)
defer store.Close()

// After a Redis failover, recover missed events:
store.Refresh(ctx)
// Live propagation to consumers — non-blocking dispatch.
for ev := range store.Watch(ctx, podshare.WatchPrefix("ws:")) {
    switch ev.Kind {
    case podshare.EventSet:
        cache.Store(ev.Key, &ev.Value)
    case podshare.EventDelete:
        cache.Delete(ev.Key)
    }
}
// Channel closes when ctx cancels or the watcher falls behind.
// Treat closure as "re-subscribe + Refresh".
// Call a method on whichever pod owns "ws:alice" — even if
// the websocket conn lives on a different pod than us.
ep, _ := callreply.New(tr, callreply.Options{SelfID: "pod-B"})
defer ep.Close()

// On the pod that owns alice's WS:
ep.Register("ws:alice", "Send", func(ctx context.Context, args []byte) ([]byte, error) {
    return nil, conn.WriteMessage(websocket.TextMessage, args)
})

// From any other pod:
ep.Call(ctx, "ws:alice", "Send", []byte("hello, alice"))

what's in the box

No leaky abstractions. Every option is documented.

⟨T⟩

Generic, type-safe

Store[T] uses Go generics. No any casts, no codegen.

⇄

Pluggable transports

Memory (tests), Redis pub/sub (boring prod), P2P TCP (no deps). Implement the Transport interface for anything else.

⏱

LWW + Seq tiebreaker

Last-write-wins by (time, origin, seq) — same-instant writes from the same node are ordered deterministically.

⌥

Watch with filtering

WatchKey / WatchPrefix apply server-side; misses don't consume buffer.

⤓

Snapshot catch-up

New pods hydrate from a persisted snapshot. Reconnects recover via Refresh.

∪

CRDT seam

WithMerger for a true commutative join — G-Sets, counters, OR-Sets converge across pods.

⚑

Tombstones with TTL

Deletes are kept long enough that late writes can't resurrect them; compacted on a periodic tick.

⊕

callreply RPC

Forward calls to whichever pod owns a target. Built on the same transport you already configured.

∿

Observable

Stats() for counters, WithLogger for slog, OnError for everything else.

where it shines

Built for small-N, hot, mutable state.

feature flags live rollout

Operator pod sets a flag; every worker pod sees it via Watch within ms. Read with atomic.Pointer for lock-free hot path.

not a fit for everything

podshare is intentionally small. Reach for something else if you need:

  • Durable source of truth — no durability guarantee. Use Postgres.
  • Large datasets — every pod holds the full map. Use sharded storage.
  • Strong consistency — LWW only. Use etcd or a real Raft library.
  • Cross-region replication — sub-millisecond intra-cluster fan-out, not WAN.
  • Order-preserving append — LWW collapses concurrent writes. Model as a G-Set + sort on read.
